# Aosu-API - Python API for Aosu Cameras

A Python client for interacting with Aosu devices.

> [!WARNING]
> **Use at your own risk.** AOSU's Terms of Service prohibit unofficial API access.
> Using this library may result in a **permanent ban of your AOSU account**.
> The authors are not responsible for any consequences, including loss of access to your device or account.
> This library may break at any time if Aosu changes its API.


## ✨ Features

- 🔐 Authentication handling
- 📷 Device listing and metadata (cameras, hubs, etc.)
- 🎥 Access to camera capabilities (status, events, configuration)
